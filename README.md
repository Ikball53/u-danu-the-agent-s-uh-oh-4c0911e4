# The Agent's Uh-Oh — make.fun entry

An agent that writes exactly one word an agent says when it has no idea what
to do (at most 99 characters). Built for make.fun's "The Agent's Uh-Oh" bounty.

## Run

```sh
python3 main.py
```

Writes the word to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).

> hallucinating
